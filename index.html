ℹ️ Sobre este ejercicio

Ejercicio educativo con cálculo simplificado, hecho para este taller — no corresponde a la metodología oficial de Global Footprint Network (footprintcalculator.org). Las cifras de comparación entre países son valores de referencia aproximados, tomados de datos públicos de Global Footprint Network y del Informe Planeta Vivo (WWF).
